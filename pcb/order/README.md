# Order lists for test plates

Generated by `make order` (`pcb/tools/order_bom.py`) from the boards' part tables. Default: 3 NA and 2 EU
plates; change with `make order NA_PLATES=4 EU_PLATES=1`.

| File | Contents |
| --- | --- |
| `na_digikey.csv`, `na_mouser.csv` | NA plate: wiring board, sensor flex, back cover flex |
| `eu_digikey.csv`, `eu_mouser.csv` | EU plate: mains board, 5 V board, EU sensor flex, back cover flex |
| `all_digikey.csv`, `all_mouser.csv` | Both variants merged by part number |
| `<name>_digikey_rest_mouser.csv` | Parts DigiKey does not carry (Marquardt 1802.2504): order these from Mouser with a DigiKey order |
| `<name>_mouser_rest_digikey.csv` | Parts Mouser does not carry (WAGO 2604-3102, Harwin P70-2200045): order these from DigiKey with a Mouser order |

## Importing

- DigiKey: myLists / BOM Manager, upload the `_digikey.csv` file and confirm the column mapping
  (Digi-Key Part Number, Manufacturer Part Number, Manufacturer, Quantity, Customer Reference). The
  DigiKey part number is the cut-tape packaging where the part comes on tape (`DIGIKEY` in
  `pcb/tools/order_bom.py`); with the MPN alone the import picks a full reel or rejects parts sold in
  several packagings.
- Mouser: BOM Import (Projects), upload the `_mouser.csv` file and confirm the column mapping
  (Mouser Part Number, Mfr Part Number, Manufacturer, Quantity, Customer Part Number). The Mouser part
  number is filled in where Mouser's import does not match the MPN (`MOUSER` in `pcb/tools/order_bom.py`).

## Quantities

Per-plate count times the plates, plus spares: half again (at least 2) for the small hand-soldered parts
(0402 passives rounded up to tens), one for the rest. Stock and pricing are not checked: some parts
(the Marquardt rocker in particular) may not be stocked by both distributors.

## Not in the lists

- The CN2 plug on both sensor flexes (part and contact map open).
- The PCBs and flexes (PCBWay), the IKEA BILRESA remotes, the Apollo MSR-2 and its GPIO add-on, 3M 467MP
  tape, the #6-32 box screws, the EU's M2 thread-forming screws, filament.
